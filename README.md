# Spotify Clone

A simple web-based music player inspired by Spotify, built with HTML, CSS, and JavaScript.

## Features
- Clean and responsive music player interface
- Play/pause controls
- Song selection from a playlist
- Visual layout for albums, songs, and player controls

## Project Structure
- index.html - Main structure of the web page
- style.css - Styling for the UI
- script.js - Music player behavior and interactivity
- images/ - Album and UI assets
- songs/ - Audio files used by the player

## How to Run
1. Open the project folder in your browser.
2. Launch index.html directly, or use a live server extension such as Live Server in VS Code.
3. Make sure the audio files in the songs folder are available and correctly referenced in the script.

## Tech Stack
- HTML
- CSS
- JavaScript

This project is a beginner-friendly frontend exercise for building a music player interface.
